# Biopharmaceutics in 3D

An interactive review deck on biopharmaceutics and pharmacokinetics (38 slides, with 3D models).

**Open the deck:** after GitHub Pages is turned on, visit `https://<your-username>.github.io/<repo-name>/`

Prepared by: Januarius P. De Gracia, RPh
Exclusive to Jaymie Lauren Martinez, RPh

## How to use
- Next / Back buttons or arrow keys to move between slides.
- Click bullets to reveal them one by one; click small cards to enlarge them.
- 3D views: drag (or one finger) to turn, pinch or + / − to zoom, two fingers to move.
- An internet connection is needed for the 3D views.
